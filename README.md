# HR-Analytics-Project
HR Analytics Dashboard project using Excel, SQL, and Power BI. This dashboard is very useful for making decision and what actual happen in the company.
## DASHBOARD PREVIEW :
           1.HR overview dashboard :
                   This page provides overall employee and attrition insights.
         
          2.Attrition Analysis Dashboard:
                      This page provides insights into employee performance, job satisfaction, work-life balance, salary distribution, and promotion analysis to evaluate workforce productivity and employee experience.
                      
            3.Employee Performance Insights Dashboard :
                       This page provides insights into employee performance, job satisfaction, work-life balance, salary distribution, and promotion analysis to evaluate workforce productivity and employee experience.
                       
** ##PROJECT OUTCOME :**
              This dashboard helps HR teams identify the major factors affecting employee attrition and workforce performance, enabling data-driven decision making.
